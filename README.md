BMSCE-Buzz is an Expo-based React Native social app with Firebase backend integration, built for campus news, events, notifications, and role-based user/admin flow.

Setup note: copy `.env.example` to `.env` in the project root so Expo can load Firebase values locally, or ensure the required `REACT_APP_FIREBASE_*` variables are set in your environment.

React Native (Expo) frontend
Firebase Auth + Firestore data model
Push notifications via Expo
News/posts + events + user profiles + admin moderation
Supports Android/iOS/Web
